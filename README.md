# Обнаружение ботов по событиям куки

Решение задания по классификации куки. Весь анализ, построение признаков, сравнение моделей и получение предсказаний находятся в [solution.ipynb](solution.ipynb). Отправленный результат — [submission.csv](submission.csv).

## Воспроизведение

1. Установить Python 3.11.0 и зависимости: `pip install -r requirements.txt`.
2. Скачать [архив по ссылке из условия задания](https://stepik.org/media/attachments/lesson/2589118/bot_detection_challenge.zip) и поместить папку `data/` с `train.csv`, `test.csv` и `events.csv.gz` в корень репозитория.
3. Из корня репозитория открыть `solution.ipynb` и выполнить все ячейки по порядку (**Run All**). Ноутбук запишет `submission.csv`.

Ноутбук импортирует официальную функцию `precision_at_recall` из предоставленного файлом задания [metric.py](metric.py). Случайное зерно — `42`; версии библиотек зафиксированы в [requirements.txt](requirements.txt).

## Подход и результат валидации

Учитываются только события внутри заданного суточного окна каждой куки. Признаки описывают темп событий, сессии, последовательности действий, поиск, разнообразие и повторяемость объявлений, популярность объявлений до момента просмотра и движение курсора между событиями. Сырой `user_agent` и идентификаторы в модель не подаются.

Валидация выполнена на трёх последовательных временных срезах: обучение на более ранних днях, проверка на следующих. По метрике Precision при Recall ≥ 70% средний результат baseline RandomForest — **0,103**, предыдущей модели без движения курсора — **0,570**, итогового CatBoost — **0,663** (по срезам: 0,617 / 0,673 / 0,700). Детали EDA, гипотезы и сравнение вариантов приведены в ноутбуке. Качество на скрытом тесте может отличаться.
